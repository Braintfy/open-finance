- `OzonInputs.fbsClusters: Array<{key, sharePct}>` — 28 кластеров FBS, weighted-sum логистика. Legacy `fbsWarehouse` → migrated через `migrateOzonRaw()`.

### v0.15.2 — UI polish + Next.js security
- **Треугольнички ▶** (incoming зелёный / outgoing индиго) на edge-точках блока, кликабельные → popover со списком cross-page целей.
- **`BlockChrome` рамка через absolute-overlay** (НЕ через `boxShadow inset` на wrapper'е) — `bg-card` детей блока перекрывал inset-shadow. `<div className="pointer-events-none absolute inset-0 z-20 rounded-lg" style={{ boxShadow: 'inset 0 0 0 2px {color}' }}>`. z-20 поверх контента (z-0/z-10), но ниже chrome (z-30). `pointer-events-none` обязателен.

## v0.16.0 — Currency Rates

### Файлы
- `src/lib/db/schema/currency.ts` — таблица `currency_rates` (НЕ tenant-scoped, общая на инстанс). PK = `code`, `rate_rub` numeric — курс **за 1 единицу**.
- `src/lib/currency/sources/cbr.ts` — `fetchCbrDaily()` (cbr-xml-daily.ru/daily_json.js, без ключа). Нормализует `Nominal>1` (KRW/JPY/HUF/IDR). Таймаут 8s + 1 retry.
- `src/lib/currency/queries.ts` — `getCurrencyRates`, `refreshCurrencyRates()` с bulk upsert.
- `src/app/api/currency/rates/{route,refresh/route}.ts` — GET с lazy-refresh при возрасте >23h, POST с rate-limit 1/min per tenant (in-memory `Map`).
- `src/lib/blocks/catalog/currency-rates.tsx` — density-aware блок с 9 «популярных» валют + диалог ~30 ЦБ.

### Инварианты
- **`rate_rub` нормализован к 1 единице** (ЦБ Nominal=10 для KRW/JPY/HUF/IDR делится).
- **Курс — НЕ money-формат.** Публикуется как `format: 'number'` БЕЗ `__money`. Иначе формула `=A1*@currency.usd` сломается (90.5 / 100 = 0.91₽).
- **Lazy-refresh 23h, не 24h** (`CURRENCY_STALENESS_WINDOW_MS`). ЦБ обновляет ~11:30 МСК.
- **`/api/blocks/sources` грузит курсы 1 раз** в начале GET → `Map<code, CurrencyRate>` → проброс в каждый `fieldsForBlock`. Не вызывать `getCurrencyRates()` ВНУТРИ — иначе N запросов.
- **In-memory rate-limit карты НЕ переживают перезагрузку** — для одиночного инстанса OK, при горизонтальном масштабе → Redis.

### Граблы аудита v0.16.0
- **Next.js HTML-500 без try/catch** → frontend падает `Unexpected end of JSON input`. Правило: ВСЕ route handlers с try/catch + `NextResponse.json({ ok: false, error })`. На клиенте — helper `parseJsonResponse(response)`.
- **Auto-refresh без guard → рекурсия.** В `useCurrencyRates()` `useRef<boolean>` flag (`triedAutoRefreshRef`).
- **Async fetch + setState после unmount** — `mountedRef = useRef(true)` + cleanup.
- **`publishColumnId` и `publish` колонки — две РАЗНЫЕ оси.** Раньше селект `publishColumnId` фильтровал `publish !== false` и был пустой если все скрыты. Фикс: показывать **все**, при выборе скрытой авто `publish: true`. Метка `· не публикуется`.

### Инварианты
- **Версионирование тарифов:** `unit_calculations.tariff_version` ссылаются на конкретный pack; не редактировать существующий pack inplace.
- **Деньги:** в БД копейки (`integer`), в JSONB — рубли с `money: true` пометкой.
- **НДС vs Налог:** отдельные строки. taxMode `nds` УДАЛЁН.
- **Multi-cluster FBS** — `Array<{key, sharePct}>`, `calculateOzon` нормализует фактическую сумму.
- **Tenant isolation:** все API под `auth()`, все DB-запросы фильтруются по `tenant_id`. Upsert по `(tenant_id, marketplace, article)`.
- **XLSX от Ozon** — `openpyxl`/SheetJS с `cellStyles:true` падают на битом border-style. Использовать `cellStyles:false` + fallback ZIP/XML.
- **Linkable cell layout** — ВСЕГДА `<input>`, в linked — `readOnly + tabIndex=-1 + onClick → picker + cursor-pointer`. Иначе сдвиг manual vs linked.
