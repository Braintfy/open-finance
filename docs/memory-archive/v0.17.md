### Инварианты
- **api_key только в `marketplace_accounts.api_key_enc`** (AES-256-GCM). На клиент → только `apiKeyMasked`.
- **`tenant_id` фильтрация ВЕЗДЕ.** `auth() → session.tenantId → getAccount({ tenantId, id })`.
- **Rate-limit per Client-Id.** Один tenant с 2 магазинами = 2 лимитера. При горизонтальном масштабе → Redis-token-bucket.
- **Backoff не ретраит 4xx** (кроме 429).
- **`runFullSync` — fire-and-forget.** Vercel `maxDuration=300`. Большие магазины (>1000 SKU + 90d) могут не успеть.
- **Per-stage прогресс через `jsonb_set`** — атомарен per-UPDATE.
- **Маппинг идемпотентен** + **никогда не перезаписывает `costKopecks`** (пользовательский ввод).
- **Plan-gate в `canAddAccount`.** Pro+ unlimited, иначе max 1 per marketplace.
- **`marketplace_account_id` в `unit_products` nullable.** XLSX-импорт NULL, sync проставляет FK. `ON DELETE SET NULL`.
- **Cron-планирование ОТЛОЖЕНО** — поля `auto_sync_enabled/cron` в схеме, BullMQ TODO.
- **`onConflictDoUpdate` + `sql\`unit_products.metadata\`** мерджит через `unit_products.metadata || ${JSON.stringify(meta)}::jsonb`. JSON.stringify обязателен.
- **`ozon_orders.delivered_at` — псевдо-derived** из `status`. Ozon API не отдаёт явное delivered_at. Точные «дни до доставки» требуют отдельного `/v3/posting/fbs/get` per posting.
- **`/v2/finance/realization` НЕ возвращает текущий месяц** — тянем 2 последних закрытых.

## v0.17.1 — Робастность

- **`OzonClient.post()` lenient по умолчанию** — на Zod safeParse fail НЕ throw, `console.warn` + return raw JSON. Опт-ин `{ strict: true }` для критичных. 4xx/5xx по-прежнему throw.
- **`SellerInfoSchema` двушаговая** — принимает и `{ result: {...} }`, и плоский.
- **`primary_image: string | string[]`** — с 2026-05 Ozon отдаёт массив URL. `normalizePrimaryImage()` нормализует. В metadata: `primaryImage` (первый) + `images` (полный список).
- **`upsertUnitProductFromOzon()` теперь возвращает `boolean`** — `false` если `info.id` или `info.offer_id` отсутствует.
- **`RATE_LIMITERS` cleanup** — `lastUsedAt` + opportunistic cleanup лимитеров старше 1ч. Без `setInterval` (для serverless).
- **`OzonKeyHelp`** — инструкция «Где взять Client-Id/Api-Key», роль **Admin read only** (238 методов), 180 дней.

### Блок `unit.ozon-analytics` (read-only аналитика per-product)

Отдельный блок (не связан с калькулятором юнит-экономики). Показывает per-product выручку/заказы/рекламу/ДРР/остатки за выбранный период.

- **`UnitOzonAnalyticsBlock`** ([`unit-ozon-analytics.tsx`](../../src/lib/blocks/catalog/unit-ozon-analytics.tsx)) — BlockDef. Pages: `unit-economics-ozon-multi` + `*`, иконка `BarChart3`.
- **Config схема** ([`unit-ozon-analytics-types.ts`](../../src/lib/blocks/catalog/unit-ozon-analytics-types.ts)) — `accountId`, `periodPreset` (today/yesterday/7d/14d/30d/mtd/custom), `customFrom`/`customTo`, `defaultFilter`, `visibleColumns`. Pure-helpers `resolvePeriod()` + тип `OzonAnalyticsRow`.
- **API `/api/marketplaces/analytics/ozon`** — один SQL с 3 CTE: `order_items` (LATERAL `jsonb_array_elements`), `agg_orders`, `agg_ads`. Spine — `unit_products`. Возвращает `rows[]` + `totals`.
- **DRR/buyout/daysOfStock в Node** (не SQL). ДРР = `ads / revenue * 100`; null если revenue=0 или ads=0. Buyout = `delivered / (delivered+cancelled+returned)`; null если total < 5. DaysOfStock = `stock / (qty_delivered / period_days)`.
- **8 smart-фильтров** (`ozon-analytics-filters.ts`): all/with-ads/high-drr/no-ads/low-stock/no-stock/no-orders/unprofitable.
- **`ozon-analytics-table.tsx`** — 13 колонок, сортировка, баджи. Sort: null/empty в конец.
- **XLSX-экспорт** через `xlsx`. `mountedRef` защищает setState. **Deleted-account fallback**.
- **+109 smoke-тестов** в `scripts/test-ozon-{upsert,sync-diff,analytics}.ts`.
