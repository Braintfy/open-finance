# Memory Archive: v0.19 — v0.20 (AI Vision, Sheet parity, kpi.grid, май 2026)

> AI Vision providers, полная фичепарность Sheet с custom.data, kpi.grid контейнер, BLOCK_PRESETS, virtual sources.

## v0.19.0 — AI Vision + Sheet полная фичепарность + Inbox dashboard

### AI Vision providers
- **`src/lib/ai/vision/`** — multi-provider абстракция для распознавания чеков/счетов/договоров.
- **`types.ts`** — `VisionProvider {id, label, supports(mt), recognize(input, hint, ctx)}`, `ExtractedData {vendor, vendorInn, date, amount (в копейках!), currency, type, items[], rawText, provider, durationMs}`, `VisionHint = 'receipt'|'invoice'|'contract'|'auto'`.
- **`buildExtractionPrompt(hint)`** — строгий JSON prompt. **`parseExtractedJson(raw)`** — терпим к markdown code-fence и messy LLM output.
- **Providers** (`providers/`):
  - `claude.ts` — Anthropic Messages API + image content blocks. Env: `ANTHROPIC_API_KEY`, опц. `ANTHROPIC_VISION_MODEL` (default `claude-3-5-sonnet-20241022`).
  - `openai.ts` — GPT-4o Chat Completions + `response_format: json_object`. Env: `OPENAI_API_KEY`, опц. `OPENAI_VISION_MODEL` (default `gpt-4o-mini`).
  - `yandex.ts` — Yandex Vision OCR + эвристический парсер. Env: `YANDEX_FOLDER_ID` + (`YANDEX_IAM_TOKEN` или `YANDEX_API_KEY`).
  - `tesseract.ts` — локальный OCR (peer dependency, dynamic import).
  - `mock.ts` — для тестов и dev fallback.
- **`router.ts`** — `getVisionProvider({override, tenantPreference})` приоритет: override → tenant → `VISION_PROVIDER` env → auto → mock. `listVisionProviders()` для UI.
- **`POST /api/inbox/messages/[id]/recognize`** — multipart upload или attachment URL. Результат в `inbox_messages.aiExtracted` + `aiProvider` + `aiExtractedAt` (миграция `drizzle/0003_inbox_ai_extracted.sql`).
- **`AiRecognizePanel`** в `inbox-channel-feed.tsx` — кнопка с выбором hint (Авто/Чек/Счёт/Договор) и провайдера, panel с extracted полями, кнопка «Создать транзакцию».

### Sheet — full parity с custom.data
- **Virtualization** при `cfg.rows > 50` (`@tanstack/react-virtual`). Estimate из `rowHeights[idx]`, overscan 10.
- **DnD reorder** колонок и строк через `@dnd-kit/sortable`. Drag-handle `GripVertical` на hover.
- **CSV/XLSX import/export** (`src/lib/blocks/catalog/sheet-import.ts`): `papaparse` + `xlsx`. Формулы roundtrip через `{t:'n', f:'B2*2', v:0}`. Лимит **10 000 ячеек**.
- Тесты в `scripts/test-sheet-import-export.ts` (16 проверок).

### Inbox dashboard блок
- `src/lib/blocks/catalog/inbox-dashboard.tsx` — компактный `inbox.dashboard` блок для дашборда (density-aware: бейдж → список 3-5). Drill-down → `/inbox`.

### Computed.sum новые aggregations
- `useBlockDependencyResult` поддерживает: `median`, `variance`, `first`, `last`, `formula`.
- **`evalFormulaVars(expression, vars)`** (в `custom-data-formulas.ts`) — безопасный eval с подстановкой `a → sources[0]`, `b → sources[1]`. Пример: `(a + b) * 0.13` — НДФЛ.
- **SettingsForm**: title, subtitle, format (auto/rub/int/percent), expression input.
- **Inline sparkline** через MiniSpark (svg polyline) если sources публикуют `byDay` строку.
- **BreakdownPopover** — список источников с контрибуцией.

### custom.data v0.19.0 (до v0.18.26)
- Multi-column блок «Данные» с `Config = { columns: Array<{id, label, format, publish, width?}>, rows: Array<{id, label, cells: Record<colId, {v, ref?, isMoney?}>}> }`.
- Per-column publish: каждая `publish:true` колонка публикует свой агрегат как `{column.id}`.
- `parseConfig` мигрирует legacy конфиги.

## v0.20.0 — Cashflow blocks rescue: source filter, virtual sources, kpi.grid

### Что добавлено
- **page-level source-filter** (`PageSourceProvider`) — Bank/Manual/Inbox/Все. `usePageSource()`, `useEffectiveSource(instanceId, blockOverride)`. localStorage `page:${pageKey}:source:v1`.
- **virtual cashflow sources** (`@__virtual:cashflow.kpi.*` для bindings без stat.* блоков). `VirtualSourcesBridge` + `useCashflowKpiLite` (`src/lib/blocks/virtual-sources.tsx`). Server-side resolver в `/api/blocks/sources` для cross-page bindings.
- **smart hint** в `useCashflowKpi` — если 0 за период, фоновый fetch all-time и UI подсказка.
- **`kpi.grid` блок** (`src/lib/blocks/catalog/kpi-grid.tsx` + `kpi-grid-settings.tsx`) — контейнер на 1–6 KPI cells (income/expense/balance/count). Layout row/column/grid-2col/grid-3col. DnD-reorder, inline override period/source/category per-cell. Publishing `cells.{id}.value` для bindings.
- **`BLOCK_PRESETS`** (`src/lib/blocks/registry.ts`) — 5 пресетов на `excel.cell` (income/expense/balance/count/delta-prev) + 3 на `kpi.grid` (3-cells row / months / 2x2 panel). `listPresetsForPage(pageKey)` / `getPreset(id)`. `AddBlockDialog` показывает отдельную секцию «Cashflow быстро».
- **`SourceFilterChips`** (`src/components/blocks/source-filter-chips.tsx`) — chips picker с counter операций.
- **`usePersistedSourceWithGlobal`** — per-block override.

### Cashflow ecosystem details
- **`PagePeriodContext`** (`src/lib/blocks/page-period-context.tsx`) — `PagePeriodProvider({pageKey, defaultPreset, children})` хранит `{preset, customFrom, customTo}`, `usePagePeriod()` для page-level UI, `useEffectivePeriod(instanceId, blockOverride)` мерджит global + per-block. localStorage `page:${pageKey}:period:v1`.
- **`usePersistedPeriodWithGlobal`** (`src/lib/blocks/use-persisted-period.ts`) — `mode: 'global'` (слушает page-level) или `mode: 'override'` (per-block).
- **`PagePeriodHeader`** — sticky `PeriodPicker` сверху страницы.
- **`DrillDown`** (`src/lib/blocks/drill-down.tsx`) — `DrillDownProvider`, `useDrillDown()`. KPI/категории/чарт → `setFocus({blockType, filter})` → таргетируется через `[data-block-type]`. Cross-page: `drillDownUrl(href, blockType, filter)` + `parseDrillDownFromSearchParams(sp)`.
- **API**:
  - `/api/cashflow/kpi` — `{current, previous, count, prevCount, deltaPct, byDay}`. Поддерживает `?metric=income|expense|balance&preset=...&counterparty=...&source=...&categoryName=...`.
  - `/api/cashflow/chart` — `{points, granularity, compare?}`. Auto-granularity: day ≤31d / week ≤120d / month иначе. `?compare=prev` overlay.
  - `/api/cashflow/top-categories` — топ-N + `totalSum`.
  - `/api/cashflow/transactions` — cursor-based pagination, filters.

### Block changes
- **`stat.income`, `stat.expense`, `stat.balance` помечены `tags: ['legacy']`** — работают, но новые пользователи добавляют через `BLOCK_PRESETS` или `kpi.grid`.
- **`StatCard`** density variants: xs (число) → sm (+ label) → md (+ trend badge) → lg (+ sparkline). Клик → drill-down. Lock-icon ↻ возвращает global период.
- **`stat.custom`** — KPI с фильтрами (metric/counterparty/categoryName/source) + sparkline + trend.
- **`chart.cashflow`** — `ChartShell` rich + `height='fill'` + compare overlay + bar/line/area + опц. накопительный баланс.
- **`cashflow.top-categories`** — % от общего, drill-down по клику.
- **`cashflow.transactions`** — header filters, cursor pagination, виртуализация при >100 строк, CSV export, drill-receive.

## v0.20.2 — kpi.grid kopecks + responsive layout

- **`kpi.grid` показывал копейки как рубли** — соседние `stat.*` делили на 100 внутри, kpi.grid — нет. Fix: `formatValue(value, format, isMoney)` делит на 100 для money-метрик на форматах rub/number/compact.
- **block-level `defaultPeriodOverride`** в kpi.grid — общий период для всех ячеек.
- **BlockGrid responsive bug**: после ресайза в узкое и обратно блоки оставались в одну колонку. Root: `react-grid-layout` auto-сжимал layout для sm/xs/xxs, `onLayoutChange` приходил со сжатыми позициями, мы их сохраняли в `blocks` → оригинальный lg-layout терялся. **Fix**: `currentBreakpointRef` (sync через `onBreakpointChange` + `recompute()` ResizeObserver). `onLayoutChange` skip-ит запись если bp != lg/md (оба 12 cols — canonical). Если layout уже корруптирован — кнопка «Настроить» → «Сбросить».
