## v0.21.0 — Source Binding для cashflow-блоков

### Концепция
KPI / chart / top-categories / kpi.grid больше не делают tenant-wide query напрямую — у каждого есть `sourceBinding: 'empty' | 'global' | {block, blockId, pageKey?}`.

- **Дефолт для НОВЫХ блоков = `empty`** (placeholder с CTA «Выбрать источник»).
- **Existing блоки auto-migrate**:
  - на странице с `cashflow.transactions` → bind к первому из них
  - без него → empty
- **`cashflow.transactions` публикует `__txFilters`** (JSON: period+type+source+counterparty+categoryName) через `useBlockValuePublisher` — это его «view», bind-able консьюмерами.
- **`kpi.grid` имеет 2 уровня** — block-level `defaultSourceBinding` + per-cell `sourceBindingOverride`.

### Mindmap edges
- `kind='data-source'` рисуются изумрудным (`#10b981`), cross-page пунктиром.

### Settings
- Общая секция «Источник данных» в `BlockSettingsDialog` для всех `BOUND_BLOCK_TYPES` (избежали дублирования в 7 SettingsForm'ах).

### Ключевые файлы
- `src/lib/blocks/source-binding.ts` — utilities, server-safe.
- `src/lib/blocks/use-bound-tx-filters.ts` — React hook.
- `src/components/blocks/source-binding-picker.tsx` — UI.
- `src/components/blocks/empty-source-placeholder.tsx` — placeholder.
- `scripts/test-source-binding.ts` — 40 тестов.

### Грабли
1. `useCashflowKpiLite` (в kpi.grid) не поддерживает counterparty/categoryName-фильтры — из bound применяются только period+source.
2. Cross-page bindings пока показывают `'missing'` (server-side endpoint уже отдаёт `txFilters`, runtime использования не подключён).
3. После миграции на дашборде без tx-блока KPI станут пустыми — это **намеренное** поведение.

См. `docs/CASHFLOW_BLOCKS.md`.

## v0.22.0 — Доработки блочной системы (4 phase'а)

### 1. custom.data гибридный formula UX
- **Общий `FormulaSession` state** (`{rowId, columnId, mode, valueDraft, formulaDraft, caretPos}`).
- **Draggable popover** (нативный pointermove, не dnd-kit).
- **Editable formula bar** (`Textarea` вместо read-only).
- **Cell-click-to-insert** в pick-mode (клик по другой ячейке → `insertIntoFormula(cellAddress(r,c))`, popover не закрывается через `onInteractOutside={(e) => e.preventDefault()}`).
- **Settings toggle `cellPopoverEnabled`** (Excel-like vs Notion-like).
- **Hint-плашка** с `localStorage['custom-data:formula-hint:dismissed']`.

См. `docs/CUSTOM_DATA_BLOCK.md`.

### 2. Глобальная панель «Период и источник» в BlockGrid
- `BlockGrid` теперь outer-wrapper с conditional `PagePeriodProvider`/`PageSourceProvider`/`VirtualSourcesBridge` (если не предоставлены ancestor'ом).
- **`usePagePeriodHeaderVisibility(pageKey, blocks)`** — auto-show панель если есть bound-блок (`stat.*`, `chart.cashflow`, `top-categories`, `kpi.grid` с `sourceBinding.mode === 'global'` или `cashflow.transactions` без `defaultPeriodOverride`).
- Иначе — collapsed (узкая полоска ~28px).
- **User override** → `localStorage[page:${pageKey}:periodHeaderHidden:v1]`, toggle-кнопка `Eye`/`EyeOff` в edit toolbar.
- `cashflow-client.tsx` упрощён — убраны ручные обёртки.

### 3. CRUD-вкладки в Юнит-экономике
- Новая таблица `unit_economics_tabs` (`src/lib/db/schema/unit-economics-tabs.ts`), tenant+user scoped, поля `pageKey`, `label`, `icon`, `order`, `kind: 'default'|'custom'`, `defaultKey`.
- API `/api/unit-economics/tabs` (GET seed + POST create/clone) + `/[id]` (PATCH rename + DELETE).
- **Default-вкладки seed'ятся автоматически** (4 шт.: ozon, ozon-multi, yandex, my-store).
- Custom pageKey = `unit-economics-custom-{nanoid8()}`.
- **Inline rename** (double-click), DropdownMenu (Rename/Duplicate/Delete), AlertDialog для confirm delete.
- Default удаление — soft, custom — hard + cleanup `block_layouts`.
- **Block marketplace поддерживает wildcard** `unit-economics-custom-*`.
- `/api/blocks/sources` динамически резолвит лейблы custom-вкладок.

См. `docs/UNIT_ECONOMICS_TABS.md`.

### 4. Import «Ozon · Аналитика» → «Мой магазин · таблица»
- **`importSource: {blockId, pageKey, columns, matchBy, mode, syncOnMount, lastImportedAt}`** в config `unit.my-store-table`.
- **Mapping utility** `src/lib/unit-economics/ozon-to-my-store.ts` — `OZON_TO_MY_STORE_COLUMN_MAP` (29 колонок) + `extractOzonValue(row, key)` с derived metrics (margin, stock, returnPct, ctr, cpc, cpm).
- **3-step wizard** `OzonImportFromAnalyticsDialog`: source-picker → multi-select колонок → matchBy + mode + syncOnMount.
- **Server endpoint** `POST /api/unit-economics/import/ozon-analytics` — читает конфиг source-блока, резолвит period, проксирует в `/api/marketplaces/analytics/ozon`.
- **Live-sync** — `useEffect` с throttle 30s через `lastSyncRef`.
- **UI-индикатор** «Импорт из Ozon Аналитики: {date} · авто-синхронизация».

### Грабли v0.22.0
1. `readSourceBinding` понимает только `mode: 'empty'|'global'|'block'` — другие значения интерпретируются как «нет binding» (legacy).
2. `BlockGrid` outer-wrapper проверяет `useContext(PagePeriodContext) === null` — если на странице уже есть свой Provider, переиспользуется.
3. Drag offset popover'а в `custom.data` сбрасывается при закрытии (by design).
4. `cashflow-client.tsx` теперь полагается на auto-mount providers в `BlockGrid`.
5. `unit_economics_tabs` schema мигрирована в `drizzle/0003_outstanding_energizer.sql` — `pnpm db:migrate` обязательна.
6. В custom-вкладках доступны все `unit.*` блоки (wildcard match) — шире, чем для default.

## v0.22.1 — UI patch + Ozon incremental sync (4 phase'а)

### A. PagePeriodHeader layout
- Chevron из `flex-wrap` переехал в отдельную Row 1. Раньше на узком экране PeriodPicker переносился и тащил chevron вниз.

### B. EmptySourcePlaceholder compact
- Семантика `title` (truncate, short) + `subtitle` (line-clamp-1, muted, «источник не привязан»).
- Compact-режим: иконка `h-6 w-6`, padding `p-1.5`, `description` скрыт.
- CTA: «Источник» (вместо «Выбрать источник»).
- Callers обновлены: `stat-custom`, `chart-cashflow`, `cashflow`, `kpi-grid`.

### C. Ozon sync API расширен
- `POST /api/marketplaces/accounts/[id]/sync` принимает `fromDate`/`toDate`/`force`. Валидация: оба или ни одного, `from ≤ to`.
- `StageContext` получил `overrideFromDate/ToDate/force`.
- **Date-aware стейджи** (`analyticsData`, `orders`, `transactions`, `perf-*`) honor override.
- **Catalog/snapshot стейджи** (`products`, `prices`, `stocks`, `turnover`, `clusters`, `warehouseStocks`, `realization`) игнорируют.
- Perf-стейджи в override-режиме делают single attempt без retry-loop.
- Helper `buildPerfPeriodFromOverride(from, to)` clamp'ит до 62d.
- Тесты: `scripts/test-ozon-sync-incremental.ts` (22).

### D. OzonSyncDialog + toolbar-кнопка
- Новый универсальный компонент `src/components/marketplaces/ozon-sync-dialog.tsx`:
  - **Диапазон дат** (preset chips «Вчера», «Последние 3/7/30 дней», «Полное окно», «Произвольный»).
  - **Стейджи** (collapsible по группам Каталог/Продажи/Реклама с smart defaults).
  - **Опции** (force).
- Polling статуса каждые 1.5s, on-completed callback.
- В `unit.ozon-analytics` toolbar добавлена кнопка `<CloudDownload> Sync` рядом с ↻ Refresh.
- По завершении — `fetchData()` re-fetch.

### Грабли v0.22.1
1. Date-override валидируется на route: `from && to` обязательны вместе, `from ≤ to`.
2. Perf-стейджи в override-режиме НЕ ретраят при 400.
3. `realization` (закрытые месяцы) override игнорирует.
4. `analyticsData` DELETE+INSERT идемпотентен — `force` зарезервирован под будущую оптимизацию.
5. Кнопка Sync в `unit.ozon-analytics` disabled если `config.accountId` пуст.
