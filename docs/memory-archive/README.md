# Memory Archive — Open Finance

> Эта папка содержит **исторические разделы** `MEMORY.md`, вынесенные туда чтобы держать основной handoff под ~180 строк.
> Файлы здесь читаются **только по запросу** конкретной задачи (не при bootstrap'е).

## Правила использования

- **НЕ грузить эти файлы по умолчанию** в новой сессии. Bootstrap читает только `START.md` + актуальный `MEMORY.md`.
- Использовать когда:
  - Пользователь спрашивает «почему мы сделали X», «когда мы перешли с Y на Z»
  - Нужны детали миграции/фикса конкретной версии
  - Работаешь с legacy-кодом, упоминающим старые конфиги/паттерны
- Альтернатива — `git log --oneline --grep="vX.Y"` если нужна только запись о факте изменения.

## Как добавлять новые архивные записи

Когда `MEMORY.md` начнёт расти — выносить старые блоки сюда. Правило: **в `MEMORY.md` оставляем только описание последних 2-3 minor-версий**, всё что старее → архив.

Шаблон записи:

```markdown
### vX.Y.Z — короткое название (YYYY-MM-DD)

**Что было**: симптом/проблема (1-2 предложения).
**Что сделали**: ключевой фикс/фича (3-5 строк, упоминаются файлы).
**Грабли**: что не повторить (если есть).
**Ссылка на коммит**: `git log -1 <hash>` или PR.
```
