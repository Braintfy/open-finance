# Onboarding-визард

> Цель: за 60 секунд узнать кто человек, что ему важно, и сразу собрать ему рабочее пространство из готовых модулей.

## Идея

Человек регистрируется → попадает в `/onboarding` → отвечает на 4–6 вопросов → AI создаёт ему первые модули, добавляет демо-данные, ведёт в дашборд.

## Шаги визарда

### Шаг 1: Кто ты

```
Чем ты занимаешься?
○ Селлер маркетплейсов (WB, Ozon, ЯМаркет)
○ ИП на услугах / фриланс
○ Малый бизнес (магазин, кафе, услуги)
○ Самозанятый
○ Просто веду личные финансы
○ Что-то ещё (укажу позже)
```

### Шаг 2: Налоговый режим (если выбрал бизнес)

```
Какой у тебя режим налогообложения?
○ УСН доходы 6%
○ УСН доходы минус расходы 15%
○ Патент (ПСН)
○ НПД (самозанятый)
○ ОСНО
○ Не знаю / помоги выбрать  ← AI задаст уточняющие вопросы
```

### Шаг 3: Что важно отслеживать

(множественный выбор)

```
☐ Денежный поток (сколько пришло / ушло / остаток по счетам)
☐ Налоги (когда платить и сколько)
☐ Поставки и закупки (когда привезут, что заплатить)
☐ Дедлайны и обязательства (отчёты, договоры, оплаты)
☐ Цели и накопления (на что копить, как идём по плану)
☐ Аналитика по продажам / каналам / товарам
```

### Шаг 4: Источники данных

```
Откуда тянуть данные?
☐ Tinkoff Business / Сбер Бизнес (загрузка выписки)
☐ WB / Ozon API (для селлеров)
☐ Excel / Google Sheets (импорт)
☐ Вручную (для начала)
☐ Telegram-чек («скинул чек, AI разнёс»)
```

### Шаг 5: AI-секретарь

```
Как удобнее общаться с AI?
○ Через сайт (чат внутри приложения)
○ В Telegram (бот @open_finance_bot — когда дойдёт)
○ По email (forward счетов, чеков → AI разнесёт)
○ Пока без AI, только сам
```

### Шаг 6: Готово

Экран «Собираю твоё пространство» с прогрессом:
- ✅ Создан tenant `Иван (ИП на УСН 6%)`
- ✅ Подключены модули: Cashflow, Taxes USN-6, Inbox, Deadlines
- ✅ Создан AI-агент «Бухгалтер УСН» с пресетом промптов
- ✅ Добавлен пример счёта для теста OCR
- ✅ Создано напоминание «Авансовый платёж УСН Q1»

→ кнопка «В дашборд»

## Шаблоны на основе ответов

| Тип пользователя | Базовые модули | AI-агенты | Демо-данные |
|------------------|----------------|-----------|-------------|
| Селлер МП | cashflow, marketplaces, supply, taxes | «Аналитик селлера», «Бухгалтер» | 5 продаж, 1 закупка |
| ИП на услугах | cashflow, taxes(usn-6 / npd), invoices, deadlines | «Бухгалтер УСН» | 3 счёта, 2 поступления |
| Малый бизнес | cashflow, taxes, deadlines, employees(заглушка) | «Финдиректор» | Базовый план |
| Самозанятый | cashflow, taxes(npd), invoices | «Помощник самозанятого» | 1 чек |
| Личные финансы | cashflow(personal), goals, budget | «Личный финансист» | 3 транзакции |
| Что-то ещё | только Cashflow + Inbox | универсальный | пусто |

## Архитектура

- `src/app/(onboarding)/page.tsx` — multi-step form (react-hook-form + zod)
- `src/lib/onboarding/templates.ts` — определения шаблонов
- `src/lib/onboarding/apply.ts` — функция которая создаёт модули, агентов, демо-данные
- API `POST /api/onboarding/complete` — принимает ответы, возвращает `{ redirectTo: '/dashboard' }`
- Флаг `tenant.onboardingCompleted: bool` в БД — если true, `/onboarding` редиректит в `/dashboard`

## Можно пропустить?

Да, кнопка «Настрою сам потом» на любом шаге. Но мы сразу подсказываем что без шаблона придётся всё собирать руками.

## Когда переделать

В Этапе 1 делаем минимальную версию (3 шага, 2 шаблона). Расширяем после первых 50 пользователей на основе их выбора.

## Связанные файлы

- `src/lib/modules/registry.ts` — список доступных модулей
- `src/lib/db/schema/tenants.ts` — поле `onboardingCompleted`, `setupAnswers` (JSON)
