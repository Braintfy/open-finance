# Open Finance — AI Финансовый Управляющий

## Миссия
**Дать каждому предпринимателю и фрилансеру персонального AI-финансиста** — уровня топового управляющего, но за доступную цену. Не просто дашборд с цифрами, а **умного советника**, который анализирует, прогнозирует, предупреждает и подсказывает решения.

## Концепция
Облачная SaaS-платформа с **модульным конструктором** — пользователь собирает свою финансовую панель как конструктор из блоков (виджеты, модули, надстройки). AI работает поверх всех данных как единый мозг: видит связи, паттерны и аномалии.

### Ключевые принципы
- **AI-first** — не аналитика с AI-довеском, а AI-управляющий с аналитикой как инструментом
- **Модульный конструктор** — каждый собирает под себя (селлер, фрилансер, ИП, малый бизнес)
- **Доступность** — сложная финансовая аналитика простым языком, понятный UX
- **Прогнозы > отчёты** — фокус на будущее, а не только фиксация прошлого
- **Единое окно** — все деньги в одном месте (МП + банки + касса + налоги)

3. Полный финучёт РФ (УСН, НДС, КУДИР, P&L)
4. Модульный конструктор (кастомный дашборд под задачу)

## Модульный конструктор (ядро продукта)

### Концепция
Пользователь выбирает модули как блоки конструктора. Каждый модуль — самостоятельный, но AI видит связи между ними.

### Базовые модули (в Free)
- **💰 Денежный поток** — доходы/расходы, баланс, тренд
- **📊 Дашборд** — виджеты drag-n-drop, кастомные графики

### Бизнес-модули (Pro)
- **🏪 Маркетплейсы** — OZON, WB, Яндекс (sync + аналитика)
- **📦 Unit-экономика** — маржа по товару, ДРР, ROAS, себестоимость
- **🧾 Налоги РФ** — все режимы (см. ниже отдельный блок)
- **🏦 Банк** — импорт выписок (Tinkoff, Сбер, Альфа)
- **💳 Платежи** — ЮKassa, Т-Касса, эквайринг, возвраты, СБП
- **🚚 Поставки и закупки** — закупки из Китая, отслеживание грузов, поставщики, ВЭД
- **📋 Заказы и клиенты** — мини-CRM, статусы заказов, источники
- **📅 Планировщик** — задачи, дедлайны, напоминания, GTD-стиль
- **📄 Документы** — УПД, акты, счета, договоры (PDF/XML парсинг)

### AI-надстройки (Pro)
- **🤖 AI Советник** — чат с финансовым ассистентом (Claude/OpenAI/Ollama)
- **🔮 Прогнозы** — cash flow forecast, сезонность, тренды
- **⚠️ Аномалии** — автодетект необычных трат, просадок маржи
- **📋 Авто-категоризация** — ML-классификация операций (>95% точность)
- **💡 Рекомендации** — «сократи расходы на логистику на 12%», «смени тариф УСН»
- **🔍 AI-валидация документов** — проверка УПД на ошибки, сверка с операциями

### Свободные блоки (Free + Pro) — Excel-like мини-модули
**КЛЮЧЕВАЯ ИДЕЯ:** пользователь создаёт свой блок с формулами, как ячейки Excel или базы данных Notion. Идёт **в базовую версию** — это foundation модульного конструктора.

- **🧮 Mini-spreadsheet** — таблица с ячейками и формулами (=SUM, =AVG, =IF, =VLOOKUP)
- **🔗 Cross-references** — ссылки на данные из других модулей (`=marketplace.ozon.revenue`)
- **🤖 AI-помощь в формулах** — «посчитай маржу с учётом комиссии 15%» → AI генерит формулу
- **📋 Шаблоны блоков:**
  - Личный бюджет (доход/расход/сбережения)
  - Поставки с Китая (закупка, доставка, растаможка, продажная цена, маржа)
  - ROI калькулятор (вложил X → получил Y → % годовых)
  - Сравнение поставщиков (цена, сроки, качество, рейтинг)
  - Долги/займы (кому, сколько, дедлайн, процент)
  - Подписки (что, сколько, когда списание)
  - Цели (накопить X к дате Y, прогресс-бар)
- **📐 Кастомные виджеты** — добавить блок на дашборд из своих данных
- **🔄 Auto-recalc** — при изменении источника пересчёт автоматический

### Пользовательские модули (будущее)
- Marketplace модулей от сообщества
- Возможность шарить шаблоны блоков
- Импорт из CSV / Excel / Google Sheets

## Налоговые режимы РФ (модуль «Налоги»)

### Поддерживаемые режимы
**КЛЮЧЕВАЯ ОСОБЕННОСТЬ:** пользователь выбирает режим при настройке + может **сравнить альтернативы** через AI-сценарий.

| Режим | Кому | Ставка | Лимит дохода | Поддержка |
|-------|------|--------|-------------|-----------|
| **УСН «Доходы» 6%** | ИП, ООО | 6% от дохода | 450 млн ₽ (2025) | MVP |
| **УСН «Доходы−Расходы» 15%** | ИП, ООО | 15% от прибыли | 450 млн ₽ | MVP |
| **НДС 5%/7%/20%** | УСН с доходом >60 млн | 5%/7%/20% | — | MVP |
| **ПСН (Патент)** | ИП | Фикс. сумма | 60 млн ₽ | Phase 2 |
| **НПД (Самозанятый)** | Физлицо, ИП | 4%/6% | 2.4 млн ₽ | Phase 2 |
| **АУСН** | ИП, ООО | 8%/20% | 60 млн ₽, до 5 чел | Phase 2 |
| **ОСНО** | ИП, ООО | НДС + НДФЛ/прибыль | — | Phase 3 |
| **ЕСХН** | Фермеры | 6% | — | По запросу |

### Функции модуля
- **Выбор режима** при первой настройке + смена через год
- **Калькулятор налогов** под выбранный режим
- **КУДИР** для УСН/ОСНО/ПСН/ЕСХН (генерация PDF/XLSX)
- **Книга учёта** для НПД, АУСН (упрощённая)
- **Авансовые платежи** — расчёт + дедлайны + напоминания
- **Декларации** — авто-заполнение шаблонов 3-НДФЛ, УСН, НДС
- **Сценарии «Что если»** — AI сравнивает: «при твоём обороте УСН 15% даст экономию 47 200₽ vs УСН 6%»
- **Льготы и вычеты** — авто-учёт страховых взносов ИП, минимальный налог УСН
- **Региональные ставки** — учёт льготных регионов (УСН 1%/5% в некоторых субъектах)
- **История изменений** — налоговые реформы 2025/2026 с уведомлениями

### Roadmap по налогам
1. **MVP:** УСН 6% + УСН 15% + НДС 5% (миграция из `/Users/firay/NALOG`)
2. **Phase 2:** ПСН, НПД, АУСН (для самозанятых и патентщиков)
3. **Phase 3:** ОСНО (для крупных ООО, требует НДС 20% и НДФЛ)
4. **Постоянно:** обновления при налоговых реформах

## AI-функциональность (детально)

### 1. Предиктивный анализ (вдохновлено Copilot Money)
Не «ты потратил X», а «при текущем темпе ты превысишь бюджет на Y к концу месяца».
- Прогноз cash flow на 30/60/90 дней
- Предупреждение о кассовых разрывах
- Сезонные паттерны (сравнение год-к-году)

### 2. Финансовый коучинг (вдохновлено Cleo)
AI даёт конкретные actionable советы простым языком:
- «Твоя маржа на товаре X упала на 8% за месяц — проверь закупочную цену»
- «Через 15 дней авансовый платёж УСН ~34 200₽ — отложи сейчас»
- «Расходы на рекламу WB выросли на 23%, но продажи только на 5% — пересмотри ставки»

### 3. Автокатегоризация (вдохновлено Monarch Money)
ML-модель на истории операций:
- Автоматическая разметка входящих транзакций
- Обучение на корректировках пользователя
- Правила + ML гибрид (>95% точность после 2 недель)

### 4. Сценарное моделирование (новый пункт, добавлено из анализа)
**Почему:** Monarch Money показал, что пользователи хотят «что если» сценарии. Для бизнеса это ещё важнее.
- «Что если поднять цену на 10%?» — пересчёт маржи, прогноз продаж
- «Что если добавить новый товар?» — оценка ROI
- «Что если перейти на НДС 5%?» — сравнение налоговых режимов

### 5. Smart-уведомления (новый пункт, добавлено из анализа)
**Почему:** Cleo доказал — nudge-уведомления меняют финансовое поведение. Для бизнеса это critical.
- Telegram / Email / Push
- Настраиваемые триггеры (маржа < X%, расход > Y, кассовый разрыв через Z дней)
- Дайджест: утренний (что было вчера) + недельный (итоги)

## Архитектура

### Стек
- **Frontend:** Next.js 15 + TypeScript + Tailwind + shadcn/ui
- **Backend:** Next.js API Routes + tRPC
- **DB SaaS:** PostgreSQL 16 (Docker) — облачный режим
- **DB Local:** SQLite WAL — desktop/local режим (один файл = простой бэкап)
- **ORM:** **Drizzle ORM** (см. обоснование ниже)
- **Cache/Queue:** Redis 7 + BullMQ (только SaaS)
- **AI:** Claude API / OpenAI API / Ollama (переключаемый провайдер)
- **Графики:** Recharts
- **Drag-n-drop:** dnd-kit
- **Связи:** ReactFlow (mindmap между модулями)
- **Desktop shell:** Tauri 2.0 (Phase 2 для local-first версии)

### Выбор ORM: Drizzle ORM (вместо Prisma)

**Что выбрано:** **Drizzle ORM** — type-safe TypeScript ORM с прямым SQL-контролем.

**Почему Drizzle лучше для Open Finance:**

| Критерий | Prisma | Drizzle | Преимущество |
|----------|--------|---------|--------------|
| Размер бандла | ~13 MB | ~7.4 KB | Drizzle ×1700 меньше |
| Производительность | Query Engine (Rust) | Прямой SQL | Drizzle быстрее в 2-5× |
| Serverless / Edge | Cold start ~300ms | Zero deps, ~10ms | Drizzle для Vercel/Cloudflare |
| RLS (multi-tenant) | Через middleware | Нативная `.enableRLS()` | Drizzle проще для SaaS |
| Type safety | Schema → generated | TypeScript-first | Drizzle строже типизирует |
| SQLite (локально) | Поддерживается | Поддерживается | Равно |
| Миграции | `prisma migrate` | `drizzle-kit` | Равно, обе хороши |
| Кривая обучения | Низкая (DSL) | Средняя (SQL) | Prisma проще для junior |

**Решение:** Drizzle. Главные причины:
1. **Одна кодовая база для SaaS (Postgres) и Local (SQLite)** — Drizzle переключается через драйвер, без изменения схемы
2. **Нативная RLS** для multi-tenant SaaS
3. **Edge-ready** — если будем выносить часть API на Cloudflare Workers
4. **Serverless cold start** — критично для Free-тарифа (масштабирование без затрат)
5. **Прямой SQL** — для финансовых отчётов нужны сложные агрегации

### Multi-Tenant (Drizzle + RLS)
```typescript
import { pgTable, uuid, text } from "drizzle-orm/pg-core";

export const transactions = pgTable("transactions", {
  id: uuid().defaultRandom().primaryKey(),
  tenantId: uuid("tenant_id").notNull(),
  amount: integer().notNull(),
  // ...
}).enableRLS();

// Установка контекста tenant перед запросом
await db.execute(sql`SET app.tenant_id = ${tenantId}`);
const rows = await db.select().from(transactions); // RLS фильтрует автоматически
```

### Роли
| Роль | Права |
|------|-------|
| owner | Всё + billing + invite |
| manager | CRUD + загрузка + дашборд |
| accountant | Read-only + экспорт + налоги |
| viewer | Только дашборд |

### Безопасность
- RLS на уровне БД (Drizzle `.enableRLS()`)
- TLS everywhere
- Docker secrets для credentials
- Rate limiting per-tenant (Redis sliding window)
- Audit log всех мутаций (отдельная таблица)
- OWASP headers (CSP, HSTS, X-Frame-Options)
- 2FA для owner-роли (TOTP)

### Мониторинг
- Sentry (ошибки frontend + backend)
- Prometheus/Grafana (метрики)
- pg_stat_statements (slow queries)
- Telegram alerting на пороги
- Health endpoint `/api/health`

### Масштабирование (рост проекта)
| Этап | Нагрузка | Архитектура |
|------|---------|-------------|
| MVP | 1-100 users | Single Postgres + 1 app instance |

| Scale | 10k-100k | Connection pooling (PgBouncer), Redis cluster, sharded queues |

## Локальная версия (Local-First) — для приватности

### Зачем нужна
**Целевая аудитория:** пользователи которые боятся утечек финансовых данных в облако (юристы, бухгалтеры, крупные ИП с чувствительными данными, параноидальные предприниматели).

**Принцип:** все данные хранятся **только на устройстве пользователя**. Никаких серверов компании не касается финансовая информация.

### Технология
- **Tauri 2.0** — обёртка приложения (.dmg, .exe, .AppImage; ~10 MB vs Electron 100+ MB)
- **SQLite WAL** — встроенная БД, файл `~/OpenFinance/data.db`
- **Drizzle ORM** — та же схема что в SaaS, переключается драйвером
- **Локальный Next.js сервер** на 127.0.0.1, открывается в системном браузере
- **System tray** — фоновая работа, sync, уведомления

### Что работает локально (без интернета)
- Все модули и виджеты
- Парсинг отчётов (xlsx/csv/pdf)
- Налоговый калькулятор
- AI через Ollama (локальная модель)
- Дашборд, графики, КУДИР
- Бэкапы (локальная копия + опционально Litestream → личный S3)

### Что требует интернета (опционально)
- Синхронизация API маркетплейсов (только если включено)
- AI через Claude/OpenAI (если выбрано вместо Ollama)
- Telegram уведомления
- Проверка лицензии (раз в N дней)

### Модели монетизации Local-First
**Выбор пользователя при покупке:**

#### Вариант A: Постоянная лицензия (Lifetime)
- Одноразовая покупка: **9 990 ₽**
- Все функции навсегда
- Обновления **1 год бесплатно**, далее +1 990 ₽/год за обновления
- Без подписки, без онлайн-проверок (offline-first)
- License key оффлайн-валидный (signed JWT с public key в приложении)

#### Вариант B: Месячная подписка
- **990 ₽/мес** или **9 900 ₽/год** (экономия 17%)
- Все функции, все обновления
- Проверка лицензии раз в 7 дней (grace period 7 дней без интернета)
- AI-кредиты включены (без своего API ключа)

#### Вариант C: Free Local (без AI)
- **0 ₽** навсегда
- Все базовые модули, парсинг отчётов, дашборд
- Без AI-советника, без API маркетплейсов, без авто-категоризации
- Идеально для тех кто хочет «просто Excel-замену»

### Архитектура лицензирования
```
┌─────────────────────────────┐
│  License Server (Cloud)     │
│  - api.openfinance.ru/license│
│  - JWT issuer (RS256)        │
│  - Tinkoff/CloudPayments     │
└──────────┬──────────────────┘
           │ HTTPS (раз в 7 дней)
           ▼
┌─────────────────────────────┐
│  Tauri App (Desktop)        │
│  - validates JWT signature  │
│  - cached license (7 дней)  │
│  - SQLite (data isolated)   │

```

### Поток покупки
1. Пользователь скачивает Tauri-приложение (Free)
2. В приложении: «Активировать Pro» → открывает браузер
3. Веб-страница с тарифами + оплата (Т-Касса / CloudPayments)
4. После оплаты — email с **license key** (или автоактивация если залогинен)
5. В приложении: ввод license key → проверка через License Server → JWT сохранён локально
6. Приложение работает offline до истечения JWT (7 дней)
7. На 6-й день — фоновое обновление JWT при наличии интернета

4. Фоновая синхронизация (BullMQ) — прогресс-бар
5. AI анализирует данные → первый инсайт на дашборде

### Платёжные шлюзы (биллинг)

**Стратегия:** **двойная резервируемость** — если один шлюз упадёт или заблокируют, переключаемся на резервный без даунтайма.

#### Основной: Т-Касса (Tinkoff/Т-Бизнес)
- **Что:** интернет-эквайринг + рекуррентные платежи (подписки)
- **API:** `https://www.tbank.ru/kassa/develop/`
- **Покрытие:** карты МИР/Visa/Mastercard, СБП, Tinkoff Pay, Yandex Pay
- **Особенности:**
  - Рекуррентные платежи через rebill-токен после первой оплаты
  - Webhooks на статусы (Authorized / Confirmed / Rejected / Refunded)
  - Чек online-кассы автоматически (54-ФЗ)
  - Поддержка фискализации через aQsi/Эвотор
- **Ставки:** 1.99-2.49% за транзакцию (карта), 0.4-0.7% (СБП)

#### Резервный: CloudPayments
- **Что:** альтернативный эквайринг с фокусом на SaaS-подписки
- **API:** `https://developers.cloudpayments.ru/`
- **Покрытие:** карты + Apple Pay + Google Pay + СБП
- **Особенности:**
  - Сильная поддержка рекуррентов (нативные «планы подписки»)
  - Без редиректа (форма открывается на сайте)
  - Splitting платежей (если будем делать партнёрскую программу)
  - Виджет на JS — быстрая интеграция за день
- **Ставки:** ~2.7% за транзакцию

#### Третий вариант (зарезервировано на будущее)
- **YooKassa (Яндекс)** — если понадобится широкое покрытие розничных карт
- **Robokassa** — для агрегации мелких платежей
- **Stripe** (если выйдем на международный рынок)

## Дедлайны и напоминания (cross-cutting feature)

### Принцип
**Любой блок, любой модуль может иметь дедлайн.** Это не отдельный модуль, а слой поверх всех остальных. Как в Notion — у любой записи можно добавить дату + напоминание.

### Где используется
| Модуль | Примеры дедлайнов |
|--------|-----------------|
| Налоги | Авансовый платёж УСН (25 апреля), декларация (30 апреля) |
| Поставки с Китая | Оплата поставщику, прибытие в порт, растаможка, доставка на склад |
| Заказы клиентов | Дата отгрузки, ожидание оплаты, гарантийные сроки |
| Планировщик | GTD-задачи, проекты, ревью |
| Документы | Истечение договора, сроки актирования |
| Подписки (Excel-блок) | Списание Notion, Claude API, домен, хостинг |
| Цели (Excel-блок) | «Накопить 500к к декабрю» — прогресс + дедлайн |

### Функции
- **Дедлайн на любом блоке** — клик «добавить дату» в любой записи (как Notion `/date`)
- **Повторения** — каждый месяц / квартал / год (для налогов и подписок)
- **Многоуровневые напоминания** — 30 / 14 / 7 / 3 / 1 день / в день
- **Каналы:** in-app banner, Telegram, Email, push (Tauri/PWA)
- **AI-приоритизация** — «3 важных дедлайна на неделю» в утреннем дайджесте
- **Календарный вид** — все дедлайны на месяц в виде календаря (`/calendar`)
- **Экспорт в iCal** — синхронизация с Apple Calendar, Google Calendar

### Пример: модуль «Поставки с Китая»
Блок поставки содержит подмодули с дедлайнами:
```
📦 Поставка #042 (футболки oversize)
├── Поставщик: Guangzhou Textile Co.
├── 💰 Оплата 1 (50%): 15.05.2026 ⏰ через 3 дня
├── 🚢 Отгрузка из порта: 28.05.2026
├── 🛃 Растаможка: ~10.06.2026 (плановая)
├── 💰 Оплата 2 (50%): при доставке
├── 📅 Прибытие на склад: 18.06.2026
└── 🏪 Запуск продаж: 22.06.2026
```
Каждая строка — дедлайн с напоминанием. AI помогает: «Запас на складе кончится 15.06, а партия только 18.06 — будет 3 дня без товара, рассмотри ускоренную логистику».

## Дизайн и UX (вдохновлено Notion, Linear, Claude Code, Codex)

### Философия
**«Сложное — простым».** Финансы — стрессовая тема. Интерфейс должен снимать стресс, а не добавлять его. Минимум визуального шума, максимум clarity.

### Ключевые UX-принципы (из лучших продуктов)

#### Из Notion
- **Slash-команды (`/`)** — добавить блок/виджет/модуль в любом месте через `/`
- **Block-based интерфейс** — каждый виджет = блок, drag/drop/duplicate/delete
- **Inline editing** — клик на любое поле редактирует на месте, без модалок
- **`@mentions`** — связать с другим модулем/блоком: `@OZON.выручка`
- **Templates** — шаблоны блоков и страниц одним кликом

#### Из Linear
- **Command palette (`Cmd+K`)** — всё через клавиатуру: добавить транзакцию, открыть модуль, перейти в настройки
- **Keyboard-first** — каждое действие имеет shortcut
- **Скорость** — мгновенный отклик, оптимистичные UI updates
- **Чистая типографика** — Inter / SF Pro, контраст 60-70%

#### Из Obsidian
- **Local-first** — нет интернета — всё работает
- **Markdown везде** — заметки в любом блоке поддерживают markdown
- **Графовая визуализация** — связи между модулями (наш ReactFlow mindmap)
- **Plugin-архитектура** — модули как плагины (наша концепция)

#### Из Claude Code / Codex (idol-tier UX)
- **Минимализм** — убраны все decorative элементы, только функциональные
- **Тёмная тема по умолчанию** — глаза не устают при долгой работе
- **Контекстная подсветка** — то что важно — выделено, остальное приглушено
- **Прогресс прозрачен** — статус операций виден в реальном времени
- **Гармония типографики** — один шрифт, 3-4 размера, 2-3 веса
- **Spacing система** — кратные 4px/8px (4, 8, 16, 24, 32, 48, 64)

**Иконки:** Lucide (единый стиль, 16/20/24 px)

### Платформы

#### Web (адаптивный)
- Desktop: трёхколоночный layout (sidebar + content + AI panel)
- Tablet: двухколоночный (sidebar collapsible)
- Mobile: одна колонка, bottom navigation, оптимизированные виджеты

#### Desktop (Tauri 2.0)
- Нативный titlebar (или кастомный с translucent background на macOS)
- System tray иконка
- Глобальные shortcuts (Cmd+Shift+O — открыть приложение)

- Установка через «Добавить на главный экран»

- Offline-first для базовых функций

### Анимации (сдержанные, как Linear)
- Длительность: 150-250ms (не дольше)
- Easing: `cubic-bezier(0.4, 0, 0.2, 1)` (Material standard)
- Не злоупотреблять — только смысловые переходы

### Accessibility
- Контраст WCAG AA (минимум)
- Keyboard navigation на 100% (без мыши работает всё)
- Screen reader labels на всех action-элементах
- Focus rings (видимые, не убираем для дизайна)

## Добавленные пункты из анализа конкурентов

### Из Copilot Money (рейтинг #1 AI-финансов)
- **Предиктивный cash flow** — прогноз баланса на 30/60/90 дней, предупреждение о кассовых разрывах
- **Авто-категоризация >95%** — ML на истории + обучение на корректировках пользователя
- **Чистый UI** — минимализм, фокус на actionable инсайты, а не на перегрузку данными

### Из Cleo (вирусный рост через coaching)
- **Финансовый коучинг** — AI говорит простым языком, даёт конкретные советы («сократи X на Y%»)
- **Nudge-уведомления** — поведенческие триггеры, которые реально меняют привычки
- **Доступный тон** — не «финансовый отчёт», а «привет, вот что важно сегодня»

### Из Monarch Money (для семей и планирования)
- **Сценарное моделирование** — «что если» для бизнес-решений
- **Долгосрочные проекции** — не только месяц, но 3-6-12 месяцев
- **Multi-user** — владелец + бухгалтер + менеджер видят разное

### Из Notion (block-based revolution)
- **Slash commands** `/` — добавление блоков и виджетов везде
- **Block editor** — каждая запись = блок с возможностями
- **Inline editing** — никаких модалок, всё редактируется на месте
- **`@mentions`** — связывание модулей и блоков ссылками
- **Templates** — готовые шаблоны блоков (бюджет, поставки, ROI)

### Из Linear (скорость + keyboard-first)
- **`Cmd+K` palette** — всё через клавиатуру за секунды
- **Оптимистичные UI updates** — действие → мгновенный отклик
- **Минимализм** — никаких лишних элементов, чистая типографика

### Из Obsidian (local-first + связи)
- **Local-first режим** — Tauri + SQLite, всё работает офлайн
- **Markdown везде** — заметки в любом блоке
- **Plugin-архитектура** — модули как плагины (наша концепция)
- **Граф связей** — наш ReactFlow mindmap

### Из Claude Code / Codex (idol-tier минимализм)
- **Тёмная тема по умолчанию** — для долгой работы с финансами
- **Контекстная подсветка** — важное выделено, остальное приглушено
- **Гармония типографики** — Inter + JetBrains Mono, 6 размеров max

### Оригинальные идеи Open Finance
- **Модульный конструктор** — ни один конкурент не даёт собирать свой дашборд из блоков
- **Excel-like блоки в базовой версии** — мини-spreadsheet с формулами и шаблонами
- **Налоги РФ нативно** — все режимы (УСН/НДС/ПСН/НПД/АУСН/ОСНО) с возможностью сравнения
- **Кросс-платформенная аналитика** — все МП + банки + касса в одном месте
- **AI поверх всех данных** — советник видит полную картину, а не только один источник
- **Local-first + Cloud** — пользователь выбирает режим под свой уровень paranoia
- **Дедлайны на любом блоке** — поставки, налоги, цели, подписки — всё в едином календаре
- **Двойная резервируемость биллинга** — Т-Касса + CloudPayments переключаются runtime
